# Erdrin Pervizaj

I work on networking, infrastructure, and software for IT operations. Based in Kosovo.

My projects focus on the practical side of running IT services: keeping track of network devices, managing support requests, and making operational information easier to work with.

## Selected projects

- **[TitanCore Community](https://github.com/pervizajerdrin/TitanBoard)** — An ISP operations project with client and package management, MikroTik monitoring, and OLT/ONU inventory. Built with React, PHP, MySQL, and a Node.js polling worker.
- **[TitanDesk Community](https://github.com/pervizajerdrin/Titan-IT-Managment)** — A helpdesk application for managing clients, tickets, tasks, and audit logs. Built with React, TypeScript, Node.js, and PostgreSQL.
- **[Node-E](https://github.com/pervizajerdrin/Node-E)** — A small command-line project in C for loading node configuration, displaying status, and logging events.

## Technical focus

Routing and switching, MikroTik RouterOS, Linux, and network troubleshooting. I also use Python for scripting and work with web applications that support network and helpdesk operations.
